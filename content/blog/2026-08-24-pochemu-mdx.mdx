---
title: Почему контент сайта лежит в git
date: 2026-08-24
tags: [разбор]
---

Записи — это файлы в репозитории, а не строки в базе CMS. Агент пишет changelog как обычный коммит, история хранится в git, деплой происходит сам. Ничего не надо админить: сайт обслуживает себя.

```bash
# коммит = публикация
git add content/changelog
git commit -m "chore: changelog"
git push
```
